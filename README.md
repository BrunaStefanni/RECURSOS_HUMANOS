# RECURSOS_HUMANOS
Repositório para desenvolvimento de projeto para trabalho do curso TDS. 

## Disciplina de Base de Dados SQL, descrições:

Este trabalho é uma base de dados destinada a apoiar empresas no processo de recrutamento e seleção de candidatos.		
O sistema permite:		
registar empresas;		
registar candidatos;		
registar recrutadores;		
criar e gerir ofertas de emprego;		
associar competências às vagas;		
registar competências dos candidatos;		
registar formação académica;		
registar experiência profissional;		
gerir candidaturas;		
acompanhar entrevistas;		
controlar o estado das candidaturas;		
analisar salários e processos de recrutamento.
